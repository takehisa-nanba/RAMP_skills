# RAMP デジタルスキルダッシュボード (PoC プロトタイプ)

浜松市「ソリューションピッチ＆ミートアップイベント（2026/09/01開催）」登壇ソリューション  
就労移行支援における「持続可能な作業周期」と企業要件の双方向接続ダッシュボード

リポジトリ: https://github.com/takehisa-nanba/RAMP_skills.git

---

## 1. システムの中核コンセプト

本システムは、研修生の弱点や能力の不足を一方的に測定・評価し、企業に提示するためのものではありません。

> **✕「この人には何ができないか（欠点・障害の提示）」**  
> 　ではなく  
> **◯「この人は、どのような条件と働き方であれば、御社にとってかけがえのない人財になり得るか」**

を可視化します。

研修生を既存の企業基準へ一方的に合わせさせるのではなく、**「本人の働き方」と「企業の業務設計」の双方を可視化し、両者の間にある隔たりと、接続できる具体的な条件を探す「働き方の設計図」**です。

---

## 2. 主な特徴と設計原則

1. **持続可能な作業周期（ワークサイクル）の可視化**:
   * 単なる連続作業時間ではなく、「集中作業時間 ＋ 回復時間」を仕事の不可欠な工程として提示。
   * 観測枠内（約90分）で安定して再現された実績を示し、勤務時間全体での持続性はお試し実習（1〜3日）で確認する設計。
2. **本人だけを測定対象にしない（双方向の事前開示）**:
   * 企業側にも具体的な業務要件（作業時間、許容ムラ幅、期待品質、用意できる環境）を事前に開示してもらい、突き合わせます。
3. **時間給与制の中に「所定労働時間内の時間配分裁量」を作る**:
   * 雇用契約は時間単位のままでも、合意時間内で「20分作業＋10分回復」などの持続可能なワークサイクルを認めることで、企業の期待基準を満たす成果を返せる根拠を提示。
4. **企業基準の変更を可視化し、合意履歴を残す**:
   * 企業要件の初期値、変更日時、バージョンを記録し、後付けでのノルマ引き上げを可視化。
   * 作業効率によって生まれた余白は、自動追加ノルマとせず、回復や別業務のバッファとして相談して決定。
5. **透明な3層の接続対話表示（自動マッチ率の完全排除）**:
   * 適合度〇％などのブラックボックス判定を行わず、事前に定義した透明なルールに基づき「🟢 すでに重なる条件」「🟡 調整で接続できる条件」「⚪ 不足している情報」を対話的に表示。
6. **需要検証データの回収とCSVエクスポート**:
   * 来場企業からの「面談・お試し実習オファー」「業務リクエスト」「アンケート感想」を蓄積し、ワンクリックでBOM付きUTF-8のCSVとして出力可能。
7. **リセット対象の完全分離**:
   * 「表示を初期状態に戻す」操作を行っても、回収したオファー・リクエスト・アンケートは一切消去されず保護。
8. **完全オフライン動作保証**:
   * 外部CDN、外部Webフォント、外部APIへの通信をゼロ化。オフライン環境下で本番起動可能。

## 4. 起動手順（オフライン環境対応）

```bash
# 依存関係のインストール (初回のみ)
npm install

# 本番用ビルドの作成
npm run build

# サーバー起動 (完全オフライン状態で起動可能)
npm run start
# => ブラウザで http://localhost:3000 にアクセス
```

## 5. デモ操作ガイド（ピッチ・展示での活用法）

画面最上部の**【視点切替バー】**から、認証なしで3つのロールをワンクリックで切り替え可能です。

### ① 企業視点（ピッチ・展示ブースの主役）
1. **業務要件の選択**: 「領収書データ入力」「Webバナー素材作成」などのプリセットを選択、または自社要件を追加。
2. **人財一覧から選択**: Aさん〜Dさんの架空モデルケース（デモ用想定値）を選択。
3. **作業周期チャートの確認**: 企業の想定時間バーと、本人の「作業＋回復サイクル」のタイムラインを比較。
4. **接続対話分析の確認**: 「すでに重なっている条件」「調整で接続できそうな条件」「お試し実習での確認事項」をチェック。
5. **オファー送信**: 「すり合わせ面談・お試し実習（1〜3日）を打診する」ボタンからオファーを送信。
6. **リクエスト・感想送信**: ヘッダーのボタンから、自社が求める業務リクエストやアンケート感想を投稿。

### ② 支援員視点
1. **研修生カルテ**: 担当研修生一覧と、月1面談での合意到達点・企業向けサマリーの編集。
2. **需要検証データ管理**: 企業から届いたオファー、業務リクエスト、感想の一覧確認。
3. **CSVエクスポート**: 【CSVエクスポート】ボタンでダウンロード。

### ③ 研修生視点
1. **日々の振り返り**: 気分、取り組んだ模擬業務、集中時間・回復時間、自己評価スライダーを入力して保存。
2. **私のトリセツ確認**: 自己対処法と合理的配慮の整理。
